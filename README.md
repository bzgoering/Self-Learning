# Self-Learning

Personal practice files for learning new programming languages.

## Languages
- Go 1.20+

## Contents
| Path | What it is |
|---|---|
| `go/general-learning/hello-world.go` | Adds two numbers given on the command line and prints "Hello, World!" that many times |

## How to run
Install [Go](https://go.dev/dl/), then:
```bash
go run go/general-learning/hello-world.go 2 3   # prints "Hello, World!" 5 times
```
